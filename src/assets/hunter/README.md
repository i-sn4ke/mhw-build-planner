# Hunter interface assets

- `monster-hunter-logo.png`: user-selected Monster Hunter logo, supplied via https://1000logos.net/wp-content/uploads/2021/07/Monster-Hunter-Logo-2004.png. Monster Hunter is a Capcom property.
- Tavern background and parchment texture: generated design assets created for this planner using the built-in image generation tool.
- `icons/`: category and UI SVGs from the existing local MHWorldData source. Its MIT license is included in `icons/LICENSE.txt`. White fills become `currentColor` so category icons can use equipment rarity colors while retaining the original black details.
- Rarity palette: MHW / Iceborne tier colors verified against https://wikiwiki.jp/nenaiko/システム/レア度. Static halo replaces the game's animation for MR rarity 10–12.

Equipment images are category symbols, not miniature depictions of individual armor or weapons.

`quest-ornament.svg` and `wood-frame.svg` are decorative vector assets authored for the interface: a repeating geometric border and a wood frame with iron corners.
